01. Tipografia & Hierarquia

O sistema adota uma tríade tipográfica cuidadosamente hierarquizada: Bebas Neue para títulos de grande impacto com suporte a traço transparente vazado, Playfair Display para toques editoriais de luxo e Inter para clareza máxima e legibilidade em corpos de texto e interfaces.

Font Families & Stacks CSS Tokens
  • Display Primário:
    --display: 'Bebas Neue', Impact, sans-serif;
  • Serif Editorial / Accent:
    --serif: 'Playfair Display', Georgia, serif;
  • Sans-Serif (Body & UI):
    --sans: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
  • Monospace (Dados & Código):
    --mono: 'JetBrains Mono', Consolas, monospace;
Estratégia de Carregamento CDN & Local

1. Pré-conexão (Preconnect): Conexões antecipadas para fonts.googleapis.com e fonts.gstatic.com via crossorigin eliminando latência de DNS lookup.

2. Font-Display Swap: Renderização imediata via fallbacks do sistema operacional, evitando FOUT (Flash of Unstyled Text) e FOIT.

3. Range de Pesos (Weight Ranges): Inter (300, 400, 500, 600, 700), Playfair Display (400, 600, 700 com suporte a Itálico), Bebas Neue (400 Regular condensado).

Cinemática & Interações

05. Animações & Transições

O movimento reforça a sofisticação do design. Transições usam funções de aceleração inspiradas na física (--ease-out-expo) garantindo respostas imediatas ao toque e surgimentos fluidos acionados via IntersectionObserver.

01. Scroll Reveal com Delays

Classes .reveal, .reveal-delay-1, .reveal-delay-2, .reveal-delay-3. Transição de 0.8s com translação vertical de 40px e opacidade progressiva.

.reveal { opacity: 0; transform: translateY(40px); transition: all 0.8s var(--ease-out-expo); } .reveal.visible { opacity: 1; transform: translateY(0); }
02. Preenchimento de Botão (Hover Slide)

Pseudo-elemento ::before que desliza lateralmente de -101% para 0% ao passar o cursor, criando efeito de luxo sem travamentos de repintura (GPU accelerated).
